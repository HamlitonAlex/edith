# PRD: 可交付的教育方案系统 MVP

状态：开发中

## 问题

当前版本只能展示事件与预设方案，用户不能从自己的情况出发获得、采用和维护一份方案，因此它不是方案系统。

## 核心交付物

一份可执行、可解释、可修订和可导出的个人或家庭教育方案，而不是一段聊天回答。

## 主流程

建档 → 澄清目标与约束 → 生成讨论稿 → 检查未知项和风险 → 用户采用第 1 版 → 执行与记录 → 条件变化时生成修订预览 → 采用新版本。

## MVP 验收

- 用户可从空白创建个人或家庭方案。
- 方案必须包含目标、起点、约束、阶段路径、近期行动、掌握证据、假设与风险。
- 家庭方案保留孩子意见状态；未确认时只能叫讨论稿。
- 时间预算会约束行动总量。
- 用户明确采用后才成为当前版本。
- 可导出 Markdown，刷新页面后仍可恢复。
- 日常采集只是执行证据入口，不是产品首页的核心交付。

## 非目标

- 不声称替代教师、心理咨询或医疗诊断。
- 不根据一次行为自动判断掌握或人格特征。
- MVP 不做课程商城、多人 AI 教师或全设备监控。
