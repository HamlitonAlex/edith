# 已确认产品定义：长期私人教育伙伴

## 产品中心

一个长期了解用户、会主动联系、会挑战用户并能在授权后执行现实任务的私人教育伙伴。用户始终通过自然对话交流；发展方案在长期互动中逐渐形成，不通过问卷一次性生成。

## 四个主要界面

1. 对话：按住说话为主，文字与连续语音为辅。
2. 发展地图：总地图与专题方案并存，实时显示已确认、观察中、候选和未知内容。
3. 它如何理解我：记忆、来源、置信度及纠正/删除入口。
4. 任务中心：简洁显示正在做、需处理、完成和失败。

## 发展地图

参考“隔壁老刘”案例的方向框架：身心基础、自主性、语言、通识、项目制、未来能力、现实能力和必要的基础学习。只继承方向结构，不普遍复制半天自学、固定日程或具体课程路径。方法必须根据年龄、意愿、目标、起点、资源和现实限制重新设计。

## 主动性与行动

主动程度由 0—1 个性化设置控制，并服从用户设置的绝对安静时段。低风险、可撤销的观察和小行动可以自动完成后通知；正式目标、重大资源变化、付费、对外沟通和影响他人的操作必须先确认。所有操作留日志，可逆操作尽量支持撤销。

## 平台与数据

Windows 与 iPhone 共享同一记忆和方案状态。默认云端高能力模型与托管同步，同时支持 BYOK、国内外兼容模型、本地模型和自托管。原始数据本地优先；用户按类别允许云端处理，敏感数据可仅留本地。首批数据源优先级为文件与笔记、微信内容、抖音收藏与观看、日历。

## 第一阶段交付

个人方案优先做深，家庭空间由主用户建立并可邀请确认。交付必须包含 Windows 安装包、可重签 IPA、完整文档、演示视频和首次公开推广。系统自身的开发与 GitHub 发布是第一个真实使用案例。
