# 后端模块 04：我的与设置

本模块对应底部“我的”页与设置页中可同步、低风险的偏好：伙伴称呼和关系、主动程度、主题、云端模型同意状态、安静时段和紧急提醒例外。

## 接口

- `GET /api/v1/profile`：取得可同步的个人设置。
- `PATCH /api/v1/profile`：局部更新用户主动修改的设置。

首页快照和“我的”使用同一份 `preferences` 记录。首页同步只覆盖它拥有的展示字段，并保留本模块的主题、安静时段等设置；没有新增第二个用户模型。

## 不会同步的内容

- BYOK API Key 和模型密钥
- 聊天全文与附件
- 原始头像图片或 Data URL
- 资料来源、授权内容与原始录音

这些字段会收到 `422 local_only_setting` 或 `422 invalid_profile`。原始头像和资料需要独立的媒体/授权模块，不能作为普通设置静默上传。

## 身份边界

开发期仍使用 `X-Xuecheng-User-Id` 占位。上线前必须替换为真实会话认证；这个模块不会把云端模型“已同意”误当作 API Key 授权，也不会代替用户打开任何外部数据连接器。
