# iPhone-first 产品方向

## 为什么改变

此前原型从“采集数据—显示任务—展示路径”出发，结果更像一个需要维护的成长后台。用户真正需要的是一个在缺少长期引导的环境中，仍能提供陪伴、判断、建议和行动安排的人。

因此产品中心从“方案系统”转向“长期关系中的行动引导”。

## 核心循环

1. 她结合长期记忆和近期状态主动发起对话。
2. 用户通过文字或按住说话自然回应。
3. 她提出观察、建议或挑战，并说明理由。
4. 建议被具体化为时间、地点或平台、内容、动作和完成标准。
5. 用户确认、修改或拒绝。
6. 她在执行前确认现实状态，执行后通过对话了解真实结果。
7. 路径地图只记录经过现实验证的变化。

## 第一阶段

- 浏览器中的 iPhone 产品原型与可安装 PWA；
- 对话、今日、路径、我们四个空间；
- 原创默认形象与本地自定义；
- 文字、按住说话、主动程度和关系定位；
- 可点击的现实内容任务；
- 明确标记尚未实现的数据连接；
- GitHub README、截图和完整运行文档。

## 后续原生化

原生 iOS 版本应优先实现通知、App Intents、Share Extension、日历授权、本地文件选择、短语音和本地队列。Windows 端随后承担文件观察、桌面通知和工具执行。Web 保持公开演示与文档，不演化成另一个独立产品后台。
